# Делегирование задач в Codex

Codex CLI установлен у владельца и работает по подписке ChatGPT (расходует лимит подписки, а не деньги). Модели проверены 2026-10-22: `gpt-6-astra` (самая сильная, для архитектуры и ревью), `gpt-5.6-sol` (модель по умолчанию), `gpt-5.6-terra`, `gpt-5.6-luna` (быстрая, для мелкой работы). Список лежит в `~/.codex/models_cache.json`, уровни рассуждения: low, medium, high, xhigh, max, ultra (у Luna без ultra).

## Как запускать
Только через `development/tools/codex-task.sh`:

```
development/tools/codex-task.sh review gpt-6-astra high <ветка-или-коммит> промпт.txt лог.txt
development/tools/codex-task.sh work gpt-5.6-luna high master промпт.txt лог.txt
```

- `review`: песочница только на чтение, ничего не пишется, временный worktree удаляется.
- `work`: песочница с записью в новом worktree и ветке `codex/<метка>`; результат проверяет координатор (тесты, независимый ревьюер) и только потом сливает.
- Codex всегда стартует в чистом worktree от указанного коммита, поэтому не видит неотслеженных секретов (корневой `.env` с токеном dev-бота). Прямой запуск `codex exec` из рабочего каталога репозитория не использовать.
- stdin закрыт (`</dev/null`), иначе Codex ждёт ввода и висит.
- Алиас `codex` в оболочке владельца указывает на несуществующий путь; скрипт зовёт `/opt/homebrew/bin/codex` напрямую (переменная `CODEX`).

## Правила
- В промпт не класть токены, пароли, данные продовой базы. Никаких обращений к проду и SSH из Codex.
- Ответ Codex это утверждение, а не факт: сверять с кодом и тестами. В первой пробе он при сломанной установке выдумал версию pnpm; после исправления окружения отвечает верно.
- Ревью опасных мест (авторизация, сеансы, миграции, изоляция окружений) делают два независимых ревьюера: Opus и Codex (Astra). Опыт 2026-10-22: Astra нашла блокирующую дыру в ветке U3–U5 (приглашение наследовалось следующим пользователем), которую Opus-ревьюер не заметил с первого прохода; Opus воспроизвёл все шесть находок.
- Песочница `read-only` не даёт запустить тесты (vitest не может создать временный каталог); для проверок поведения Codex пишет сценарии в памяти или использует режим `work`.
